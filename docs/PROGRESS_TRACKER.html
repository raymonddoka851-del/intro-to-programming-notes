Most common errors checklist

  • ☐ = instead of == in a condition
  • ☐ Semicolon after if, for or while
  • ☐ Missing & in scanf
  • ☐ Integer division when a decimal answer is needed
  • ☐ % used with float/double
  • ☐ Missing break in switch
  • ☐ Array index out of bounds / loop uses <=
  • ☐ Missing '\0' in a hand-built string
  • ☐ Uninitialised variable
  • ☐ Missing return in a non-void function
  • ☐ File opened but not closed / fopen not checked
  • ☐ Wrong format specifier (%d with float, %s with a char)

8. Final 7-day checklist

Knowledge

  • ☐ I can define program, programming, language, algorithm, pseudocode, flowchart
  • ☐ I can list the 8 development phases in order
  • ☐ I can explain compiler vs interpreter (4 differences)
  • ☐ I can convert decimal ↔ binary ↔ octal ↔ hex without help
  • ☐ I can do 8-bit two's complement
  • ☐ I can state sizes and format specifiers for the main types
  • ☐ I can reproduce the operator precedence table
  • ☐ I can write if/else-if/switch from memory
  • ☐ I can write while/do-while/for and nested loops
  • ☐ I can write and call functions, including a recursive one
  • ☐ I can declare and process 1D and 2D arrays
  • ☐ I can use strings and the main <string.h> functions
  • ☐ I can use &, *, pointer arithmetic and pass by reference
  • ☐ I can define a struct, array of structs, typedef and ->
  • ☐ I can explain struct vs union
  • ☐ I can open, write, read and close a file
  • ☐ I can format a report with widths and precision

Exam technique

  • ☐ I have attempted a full 70-mark paper in 2 hours
  • ☐ I know to do definitions first, then tracing, then programs
  • ☐ I always write declarations, input, process, output and return 0;
  • ☐ I check every scanf for &
  • ☐ I dry-run every program with a small example
  • ☐ I leave no question blank
