Code Examples

All programs are standard C (C99 or later) and compile with:

gcc -Wall -Wextra program.c -o program

Run:

./program          # Linux / macOS
program.exe        # Windows

Or paste any file into <https://www.onlinegdb.com/online_c_compiler> and press Run.
