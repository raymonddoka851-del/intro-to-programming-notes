Note 05 — Control Statements: Selection

Covers outline Week 7 (if, if..else, nested if). Also includes switch, because it is in your Week 4/6 notes and is examinable.

1. The three control structures

Every program, no matter how complex, can be built from three structures:

1. SEQUENCE         2. SELECTION          3. REPETITION
   statement 1         condition?             while (condition)
   statement 2        /          \               statement
   statement 3     true          false
                  block A       block B

This note covers selection (also called branching or decision control).

Selection is used when the program must choose between alternatives:

if (weather == SUNNY)
    play_outside();
else
    stay_inside();

C provides:

  • if
  • if-else
  • else-if ladder
  • nested if
  • switch
  • the conditional operator ?: (Note 04)

2. The if statement

2.1 Syntax

if (condition)
{
    /* statements executed only if condition is true */
}

or, for a single statement, the braces are optional (but recommended):

if (condition)
    statement;

2.2 How it works

        ┌───────────────┐
        │   condition?  │
        └──┬─────────┬──┘
        true       false
          │          │
          ▼          ▼
   ┌────────────┐    │
   │ statements │    │
   └─────┬──────┘    │
         └─────┬─────┘
               ▼
          rest of program

2.3 Example: print a message if a number is negative

#include <stdio.h>

int main(void)
{
    int number;

    printf("Enter a number: ");
    scanf("%d", &number);

    if (number < 0)
    {
        printf("The number is negative.\n");
        number = -number;          /* make it positive */
    }

    printf("Value = %d\n", number);
    return 0;
}

Run 1

Enter a number: 6
Value = 6

Run 2

Enter a number: -2
The number is negative.
Value = 2

2.4 Example: avoid division by zero

#include <stdio.h>

int main(void)
{
    int a, b;
    float quotient;

    printf("Enter two integers: ");
    scanf("%d %d", &a, &b);

    if (b == 0)
    {
        printf("Division by zero is not allowed.\n");
        return 1;
    }

    quotient = (float)a / b;
    printf("Quotient = %.2f\n", quotient);
    return 0;
}

3. The if-else statement

3.1 Syntax

if (condition)
{
    /* if block: runs when true */
}
else
{
    /* else block: runs when false */
}

Exactly one of the two blocks runs — never both, never neither.

3.2 Example: even or odd

#include <stdio.h>

int main(void)
{
    int n;

    printf("Enter an integer: ");
    scanf("%d", &n);

    if (n % 2 == 0)
        printf("Even\n");
    else
        printf("Odd\n");

    return 0;
}

3.3 Example: largest of two numbers

#include <stdio.h>

int main(void)
{
    int a, b;

    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    if (a > b)
        printf("%d is larger\n", a);
    else if (b > a)
        printf("%d is larger\n", b);
    else
        printf("Both are equal\n");

    return 0;
}

3.4 Example: leap year

A year is a leap year if:

  • it is divisible by 4 and not divisible by 100, or
  • it is divisible by 400.
#include <stdio.h>

int main(void)
{
    int year;

    printf("Enter a year: ");
    scanf("%d", &year);

    if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0))
        printf("%d is a leap year.\n", year);
    else
        printf("%d is not a leap year.\n", year);

    return 0;
}

Test values: 1996 (leap), 2000 (leap), 1900 (not leap), 2015 (not leap), 2024 (leap).

4. The else-if ladder

Use this when there are several mutually exclusive alternatives.

4.1 Syntax

if (condition1)
{
    /* block 1 */
}
else if (condition2)
{
    /* block 2 */
}
else if (condition3)
{
    /* block 3 */
}
else
{
    /* default block */
}

The conditions are tested top to bottom. The first true condition wins; the rest are skipped.

4.2 Example: grade classification

#include <stdio.h>

int main(void)
{
    int score;

    printf("Enter score (0-100): ");
    scanf("%d", &score);

    if (score < 0 || score > 100)
        printf("Invalid score\n");
    else if (score >= 70)
        printf("Grade A\n");
    else if (score >= 60)
        printf("Grade B\n");
    else if (score >= 50)
        printf("Grade C\n");
    else if (score >= 40)
        printf("Grade D\n");
    else
        printf("Grade F\n");

    return 0;
}

Why this order? Because >= 70 is checked first, a score of 75 never reaches >= 60. If you reversed the order, everyone above 40 would get a D.

4.3 Example: largest of three numbers

#include <stdio.h>

int main(void)
{
    int a, b, c;

    printf("Enter three numbers: ");
    scanf("%d %d %d", &a, &b, &c);

    if (a >= b && a >= c)
        printf("%d is the largest\n", a);
    else if (b >= a && b >= c)
        printf("%d is the largest\n", b);
    else
        printf("%d is the largest\n", c);

    return 0;
}

4.4 Example: character type

#include <stdio.h>

int main(void)
{
    char ch;

    printf("Enter a character: ");
    scanf(" %c", &ch);          /* the space skips leftover whitespace */

    if (ch >= 'A' && ch <= 'Z')
        printf("Uppercase letter\n");
    else if (ch >= 'a' && ch <= 'z')
        printf("Lowercase letter\n");
    else if (ch >= '0' && ch <= '9')
        printf("Digit\n");
    else
        printf("Other character\n");

    return 0;
}

5. Nested if

An if (or if-else) placed inside another if or else block.

5.1 Syntax

if (condition1)
{
    if (condition2)
    {
        /* both true */
    }
    else
    {
        /* condition1 true, condition2 false */
    }
}
else
{
    /* condition1 false */
}

5.2 Example: positive numbers and which is larger

#include <stdio.h>

int main(void)
{
    int m = 40, n = 20;

    if (m > 0 && n > 0)
    {
        printf("Both numbers are positive\n");

        if (m > n)
            printf("m is greater than n\n");
        else if (m < n)
            printf("m is less than n\n");
        else
            printf("m is equal to n\n");
    }
    else
    {
        printf("At least one number is not positive\n");
    }

    return 0;
}

Output

Both numbers are positive
m is greater than n

5.3 The dangling-else problem

An else always binds to the nearest unmatched if.

if (a > 0)
    if (b > 0)
        printf("both positive\n");
else
    printf("a is not positive\n");     /* WRONG indentation: else belongs to inner if */

The compiler sees:

if (a > 0)
{
    if (b > 0)
        printf("both positive\n");
    else
        printf("b is not positive\n");   /* this is what it actually means */
}

Fix: always use braces.

if (a > 0)
{
    if (b > 0)
        printf("both positive\n");
}
else
{
    printf("a is not positive\n");
}

6. The switch statement

switch is a multi-way decision that compares one integer or character expression against several constant cases.

6.1 Syntax

switch (expression)
{
    case constant1:
        statements;
        break;
    case constant2:
        statements;
        break;
    case constant3:
        statements;
        break;
    default:
        statements;
}

6.2 Rules

6.3 Example: grade remarks

#include <stdio.h>

int main(void)
{
    char grade;

    printf("Enter grade: ");
    scanf(" %c", &grade);

    switch (grade)
    {
        case 'A':
            printf("Outstanding!\n");
            break;
        case 'B':
            printf("Excellent!\n");
            break;
        case 'C':
            printf("Well done\n");
            break;
        case 'D':
            printf("You passed\n");
            break;
        case 'F':
            printf("Better try again\n");
            break;
        default:
            printf("Invalid grade\n");
    }

    printf("Your grade is %c\n", grade);
    return 0;
}

6.4 Fall-through demonstration

int i = 2;
switch (i)
{
    case 1: printf("I am in case 1\n");
    case 2: printf("I am in case 2\n");
    case 3: printf("I am in case 3\n");
    default: printf("I am in default\n");
}

Output

I am in case 2
I am in case 3
I am in default

Because there is no break, execution continues downward. Add break to each case if you want only one message.

Intentional fall-through is sometimes useful:

switch (month)
{
    case 12:
    case 1:
    case 2:
        printf("Winter\n");
        break;
    case 3: case 4: case 5:
        printf("Spring\n");
        break;
    /* ... */
}

6.5 Example: simple calculator

#include <stdio.h>

int main(void)
{
    char op;
    float a, b;

    printf("Enter expression (e.g. 5 + 3): ");
    scanf("%f %c %f", &a, &op, &b);

    switch (op)
    {
        case '+':
            printf("%.2f\n", a + b);
            break;
        case '-':
            printf("%.2f\n", a - b);
            break;
        case '*':
            printf("%.2f\n", a * b);
            break;
        case '/':
            if (b != 0)
                printf("%.2f\n", a / b);
            else
                printf("Division by zero is not allowed\n");
            break;
        default:
            printf("Invalid operator\n");
    }

    return 0;
}

6.6 switch vs if-else

switchif-else
Tests one expression against constant casesCan test any condition, including ranges
Only integer/char/enum expressionsAny expression, including float and strings
Cleaner for many fixed choices (menus)Better for ranges and complex logic
Uses break to prevent fall-throughNo fall-through concept
Can be faster (jump table)Evaluated in order

7. Worked traces

Trace 1

int x = 10;
if (x > 5)
    printf("A");
if (x > 8)
    printf("B");
else
    printf("C");

Output: AB

  • First if is independent → A.
  • Second if true → B; the else is skipped.

Trace 2

int x = 3;
if (x > 5)
    printf("A");
else if (x > 2)
    printf("B");
else if (x > 1)
    printf("C");
else
    printf("D");

Output: B

The first true condition wins; x > 1 is never checked.

Trace 3

int a = 5, b = 10;
if (a > 3)
    if (b > 20)
        printf("X");
    else
        printf("Y");

Output: Y

The else belongs to the inner if (b > 20 is false).

Trace 4

int i = 2;
switch (i)
{
    case 1: printf("One ");
    case 2: printf("Two ");
    case 3: printf("Three ");
    default: printf("Default");
}

Output: Two Three Default

Trace 5

int i = 5;
switch (i)
{
    case 1: printf("One");
    case 2: printf("Two"); break;
    default: printf("Default");
}

Output: Default

No case matches; execution jumps to default.

8. Common errors

ErrorExplanationFix
if (x = 5)Assignment, not comparison; always trueif (x == 5)
if (x > 5);Semicolon ends the if; the next statement always runsRemove the semicolon
Missing bracesOnly the first statement is controlledAlways use { }
else without ifSyntax errorMatch each else
Dangling elseBinds to nearest ifUse braces
if (a < b < c)Evaluates (a < b) < c, i.e. 0 < c or 1 < cif (a < b && b < c)
switch on float/stringNot allowedUse if-else or strcmp
Missing breakUnwanted fall-throughAdd break
Duplicate caseCompile errorUse unique constants
case x: where x is a variableCase labels must be constantUse a constant or if
Comparing floats with ==Precision problemsCompare with a tolerance
if (x == 0.1)Same problemfabs(x - 0.1) < 1e-9

9. Exam-style programs to practise

10. Rapid revision

  • if (condition) { ... } — runs the block only if true.
  • if-else — exactly one of two blocks runs.
  • else-if ladder — first true condition wins; order matters.
  • Nested if — an if inside another; use braces to avoid dangling else.
  • switch — integer/char expression, constant cases, break, optional default.
  • Missing break causes fall-through.
  • = vs == is the most common bug.
  • Never put a semicolon after if (...).
  • For ranges, use if-else; for fixed choices, switch.
