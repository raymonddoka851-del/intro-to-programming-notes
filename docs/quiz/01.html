Quiz 01: Programming fundamentals

Ten questions. Pick one answer to get instant feedback. Your best score is saved on this device.

0 / 10Best: 0 / 10

1. What is an algorithm?

An algorithm is the ordered logic, independent of any language.

2. Which is NOT a characteristic of a good program?

A good program terminates and is easy to maintain.

3. What does a compiler do?

Compilation happens before the program runs.

4. Which phase of program development comes first?

You must understand inputs, outputs and requirements first.

5. A missing semicolon is which kind of error?

The compiler rejects invalid syntax before execution.

6. Machine language instructions are written as

The CPU executes binary machine instructions.

7. Which flowchart symbol represents a decision?

A diamond has Yes/No branches.

8. Pseudocode is

Pseudocode expresses logic without language syntax.

9. Which is a runtime error?

The program compiles but fails while running.

10. Which of these is a high-level language?

C is high-level compared with machine and assembly language.
