Quiz 06: Loops

Ten questions. Pick one answer to get instant feedback. Your best score is saved on this device.

0 / 10Best: 0 / 10

1. for (;;) creates

There is no terminating condition.

2. A while loop checks its condition

If false at the start, the body never runs.

3. A do-while loop checks its condition

The body always runs at least once.

4. break inside a loop

Control continues after the loop.

5. continue inside a loop

The rest of the body is skipped.

6. How many times does for (i = 0; i < 5; i++) run?

i takes the values 0 to 4.

7. A loop inside another loop is called

The inner loop completes for each outer iteration.

8. Using i <= 5 instead of i < 5 when you want 5 iterations causes

You get one extra iteration.

9. What is 1 + 2 + ... + 10?

The sum is 55.

10. In for (i = 0; i < 3; i++), when does i++ run?

It runs after the body, before the next condition check.
